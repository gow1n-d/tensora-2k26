## 🌟 Overview

**TENSORA 2026** is a prestigious national-level hackathon engineered to challenge forward-thinking undergraduate and postgraduate student engineers, developers, and AI researchers across India. Participants tackle high-impact, real-world problems curated across critical domains—delivering functional, end-to-end AI/ML software architectures and hardware prototypes.

### 🔑 Key Highlights

- **Hybrid Format:** 24-Hour continuous online build sprint followed by an elite offline grand finale defense.
- **AI Is Non-Negotiable:** Every project must integrate functional machine learning, deep learning, computer vision, NLP, or autonomous LLM agents.
- **Industry Standard Judging:** Evaluated by distinguished AI researchers, cloud architects, and industry engineering leaders.
- **Team Size:** 2 to 4 student innovators per team.

## ✨ Website & Platform Features

This repository contains the official production web platform for **TENSORA 2026**, built with cutting-edge frontend engineering principles:

- 🌌 **Cyber-Glassmorphic UI/UX**: Custom design system featuring deep space backgrounds (`#040711`), ambient neon glow meshes, glassmorphism containers (`backdrop-filter`), and fluid CSS typography (`Outfit`, `Inter`, `JetBrains Mono`).
- ⏱️ **Adaptive Multi-Phase Countdown**: Real-time IST-synchronized countdown that dynamically updates across event milestones:
  - *Phase 1:* Challenge Reveal Countdown (21 Sept, 5:00 PM IST)
  - *Phase 2:* 24-Hour Online Build Sprint (21 Sept, 6:00 PM IST)
  - *Phase 3:* Project Submission Window (22 Sept, 6:00 PM IST)
  - *Phase 4:* Offline Grand Finale (23 Sept, 9:00 AM IST)
- 🔍 **Interactive 20-Challenge Problem Statement Explorer**:
  - Live filtering across 5 innovation tracks.
  - Difficulty badges (*Intermediate*, *Advanced*, *Specialist*).
  - Search engine with instant client-side query matching.
  - Comprehensive problem detail modals featuring Problem Scope, Mandatory AI Requirements, Deliverables, and Curated Datasets.
- 📋 **Integrated Team Registration Modal**:
  - Dynamic member allocation (2–4 team members).
  - Client-side validation with real-time feedback.
  - Team leader and member profile management.
  - Registration summary receipt generation.
- 🚀 **Submission Portal**:
  - Verified submission intake with GitHub repository validation, live video demo URL, presentation deck link, and tech stack tags.
- ❓ **Searchable & Categorized FAQ Accordion**:
  - Instant query filtering and category tabs (General, Registration, Technical & AI, Submission & Grand Finale).
- 📱 **100% Fully Responsive Layout**:
  - Optimized for mobile, tablet, laptop, and ultra-wide displays with touch-friendly navigation drawer.

## 🎯 Innovation Tracks & Themes

TENSORA 2026 offers 20 curated problem statements spread across 5 cutting-edge tracks:

### 1. 🚆 Intelligent Mobility & Smart Transport
- AI-based predictive maintenance for metro train compressor units.
- Edge-AI driver distraction, drowsiness, and cognitive fatigue prevention.
- Computer-vision-powered runway foreign object debris (FOD) detection.
- Dynamic urban traffic flow optimization using reinforcement learning.

### 2. 🏥 Healthcare, BioAI & Assistive Tech
- Multi-modal chest pathology diagnostic assistance (X-Ray + Clinical EHR).
- Real-time surgical tool tracking and anomaly detection in laparoscopic feeds.
- Edge-AI wearable seizure detection and emergency broadcast system.
- Multilingual conversational clinical voice agent with automated EHR synthesis.

### 3. 🌾 Smart Agriculture, Water & Climate Resilience
- UAV multispectral crop disease diagnostics & localized chemical spraying map generator.
- AI-driven hyper-local groundwater table depletion forecasting.
- Automated fruit grading, defect detection, and shelf-life prediction.
- Precision soil nutrient estimation and climate-adaptive crop recommender.

### 4. 🧠 Generative AI, LLMs & Autonomous Agents
- Autonomous code security auditor and automated zero-day vulnerability patch agent.
- High-fidelity synthetic tabular data synthesizer with Differential Privacy.
- Multimodal hallucination detector & claim verification engine for LLM outputs.
- Autonomous multi-agent software engineering squad (Architect, Coder, Reviewer, QA).

### 5. 🌐 Open Innovation & Civic Tech
- Deepfake video & cloned voice forensic verification engine.
- Satellite-imagery-based disaster damage assessment & rescue routing agent.
- Edge-AI smart micro-grid load balancing & renewable energy arbitrage.
- Real-time Indian Sign Language (ISL) two-way dynamic conversational translator.

## 🚀 Quick Start & Local Development

No package manager or build pipeline is required. Run directly in any modern web browser:

### Option 1: Using Python HTTP Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/gow1n-d/tensora-2k26.git

# Navigate into the project folder
cd tensora-2k26

# Launch a local development server
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your web browser.

### Option 2: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Direct Browser Launch
Simply double-click `index.html` in your file explorer to open it in your browser.
